TERMINOLOGY REFERENCE (use these codes directly; they are pre-verified)

Code systems and their canonical URLs:
- LOINC (labs, vitals): http://loinc.org
- SNOMED CT (problems, findings, procedures): http://snomed.info/sct
- RxNorm (medications): http://www.nlm.nih.gov/research/umls/rxnorm
- UCUM (units): http://unitsofmeasure.org

Searching:
- search_terminology is reliable ONLY for LOINC (http://loinc.org). Call it when
  you need a LOINC code you do not already know.
- Do NOT call search_terminology for SNOMED CT or RxNorm; those searches fail on
  this server and waste turns. Use a code listed below, a code stated in the note,
  or omit the coding and provide only the text.
- If no suitable code is known, add the resource with display text only rather
  than guessing a code or searching repeatedly.
